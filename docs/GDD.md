# 계승자들 — 게임 기획서 (v0.1)

> 가문의 검을 대대로 물려주는 픽셀 방치형 RPG.
> 영웅은 늙고, 은퇴하고, 자녀가 그 피를 이어받는다.

---

## 1. 한 줄 요약과 차별점

| | 기존 방치형 RPG | 계승자들 |
|---|---|---|
| 성장 대상 | 영웅 한 명(또는 수집 캐릭터)의 숫자 | **혈통** — 세대마다 바뀌는 영웅들 |
| 환생(프레스티지) | 버튼 하나로 리셋, 감정 없음 | **은퇴 → 혼인 → 후계자 선택**, 이야기가 있는 리셋 |
| 수집 | 정해진 캐릭터 목록 | 유전 조합으로 **사실상 무한한 영웅**, 가계도가 곧 도감 |
| 시간 | 쌓이기만 함 | 영웅이 **실제 시간으로 나이를 먹음** → "언제 은퇴시킬까"가 핵심 판단 |
| 공유 | 전투력 숫자 | **우리 가문 가계도 이미지** (SNS 공유 → 바이럴) |

### 핵심 재미 3가지
1. **핏줄 육성** — 좋은 특성을 가진 배우자를 맞아 원하는 특성을 고정시키는 '브리딩' 재미 (같은 특성끼리 결혼하면 유전 확률 50% → 75%).
2. **은퇴 타이밍** — 나이에 따라 전투력이 청년기 → 전성기 → 노년기로 변한다. 더 버틸지, 지금 넘겨줄지 고민하게 만든다.
3. **가문 서사** — 1대 시조부터 이어지는 가계도. 하늘이 인생의 하루처럼 새벽(청년) → 노을(노년) → 밤(은퇴)으로 바뀐다.

---

## 2. 타깃

- **1차:** 한국·일본의 방치형 RPG 유저 (20~40대). 수집·육성에 돈을 쓰는 층.
- **2차:** 가볍게 즐기는 캐주얼 유저. 픽셀 감성 + 가족 이야기로 유입.
- 세션: 하루 5~8회, 1회 2~5분 접속 + 오프라인 방치.

---

## 3. 게임 루프

| 주기 | 플레이어가 하는 일 |
|---|---|
| 몇 초 | 자동 전투 구경, 골드로 수련(공격·체력·공속) 업그레이드 |
| 한 세션 (2~5분) | 오프라인 보상 받기(광고 2배), 업그레이드, 보스 돌파 |
| 한 세대 (라이브 기준 3~6시간) | 영웅 성장 → 전성기 → 벽에 막힘 → **은퇴** → 명성 획득 |
| 하루 | 2~4세대 진행, 일일 미션, 혼담 확인 |
| 주 | 가문 랭킹 시즌, 이벤트 특성, 친구 가문과 혼인 동맹 |

## 4. 시스템 (프로토타입에 구현된 것은 ✅)

### 4.1 전투 ✅
- **보스 도전 (v0.5.1, 방치형 장르의 표준 방식 — 사용자 제보 스크린샷 기준)**: 잡몹은 끝없이 나오고, 스테이지 이름 옆 **☠ BOSS** 버튼을 누르면 **언제든** 그 스테이지의 보스가 나타난다. 누르지 않으면 같은 스테이지에서 잡몹만 잡으며 골드를 모은다.
  - **「자동 도전 켬/끔」**: 켜 두면 그 스테이지에서 잡몹 5마리를 잡은 뒤 알아서 도전. 지면 전투력이 1.15배 오를 때까지 기다렸다가 다시 자동 도전. 끄면 버튼을 누를 때까지 잡몹만.
  - 보스를 이기면 다음 스테이지. 지거나 시간이 끝나면 **같은 스테이지에 남아** 잡몹 사냥 계속 (스테이지가 떨어지지 않음).
  - 보스 2종: 매 스테이지 **정예 보스**(같은 몬스터가 1.35배 크기·붉은 그림자, 체력 2.5배·공격 1.5배·골드 5배, 20초), 10스테이지마다 **지역 보스**(골렘·설인·화염 용, 체력 5배·공격 2배·골드 15배, 30초, 유산석, 버튼이 깜빡임).
  - **보너스 상자 게이지**: 스테이지 이름 아래 주황 막대. 잡몹을 40마리 잡을 때마다 가득 차고, 상자가 떨어져 열리며 **보너스 골드**(지금 스테이지 잡몹 8마리분)가 쏟아진다. 보스 도전과는 별개이며 스테이지가 바뀌어도 이어진다. (우리 게임엔 경험치가 없어서 골드만)
  - 우리만의 점: 세대가 바뀌어 **선대가 정복한 땅(최고 기록의 80% 아래)** 에서는 버튼 없이 빠르게 진군하고, 지역 보스만 자동으로 넘는다.
  - 잡몹에게 쓰러지면 한 스테이지 뒤로.
  - 우리만의 점: 세대가 바뀌어 **선대가 정복한 땅(최고 기록의 80% 아래)** 에서는 정예 보스 없이 빠르게 진군하고, 지역 보스만 자동으로 넘는다.
- **쓰러지면 2초 뒤 부활 + 6초간 부상**(공격력 -25%).
- **빠른 진군**: 가문 최고 기록의 80% 아래 스테이지는 몬스터 1마리·짧은 간격 → 새 가주가 선대가 닦은 길을 순식간에 지나간다.
- 지역 20스테이지마다 변경: 초록 들판 → 안개 숲 → 잿빛 유적 → 얼어붙은 설원 → 불타는 화산 (100스테이지 뒤로는 반복). 새 지역에 들어서면 이름 표시.
- 보스: 들판·숲·유적은 골렘(색 변형), 설원은 설인, 화산은 화염 용. 보스는 **유산석**을 떨어뜨린다 (1 + 스테이지/30).
- 전투 로직(`src/core/battle.ts`)은 화면과 분리 → 서버 검증·오프라인 계산에 그대로 사용 가능.

### 4.2 수련(업그레이드) ✅
- 검술 수련(공격), 체력 단련(체력), 발놀림(공속, 최대 50).
- 비용 = 기본 × 1.15^레벨, **25레벨마다 배율 ×2 '돌파'**.

### 4.3 나이와 수명 ✅
- 18세 시작, 기본 수명 58세 + 체력 유전자 보정 + 특성(장수·불사조).
- 1년의 길이는 세대마다 1.35배씩 길어진다: 1대 30초 → 2대 40초 → … 최대 4분. 1대는 첫 접속에서 은퇴까지 경험하고, 후반 세대는 방치 시간이 넉넉하다.
- 나이 보정: 청년 0.8 → 전성기 1.12 → 노년 0.65 (`ageMultiplier`).
- 30세부터 자발적 은퇴 가능. 수명이 다하면 강제 은퇴.
- 오프라인 동안에는 **절반 속도**로 나이를 먹음 (자고 일어났더니 은퇴해 있는 상황 완화).

### 4.4 은퇴와 명성 ✅
- 은퇴 시 명성 = ⌊3 × 1.09^(최고 스테이지 − 10)⌋ × 특성 보정. **스테이지에 따라 기하급수로** 늘어서 세대마다 꾸준히 더 멀리 간다.
- 명성 1당 공격·체력·골드 +5% (영구). 화면에는 배율(x8.55, x8.75만 …)로 표시.
- 초기화: 골드, 수련, 스테이지. 유지: 명성, 보석, 가계도, **유전자**.

### 4.5 혼인과 유전 ✅
- 배우자 후보 3명. 명성이 높을수록 좋은 후보(능력치 평균↑, 특성 확률↑).
- 자녀 후보 3명 중 후계자 선택.
- **능력치**(힘·체력·민첩): 부모 평균 + 정규분포 노이즈(σ=8).
- **특성**: 부모 각 특성이 50%로 전달, 둘 다 가진 특성은 75%. 최대 2개.
- **돌연변이** 6%: 일반 60% / 희귀 28% / 영웅 10% / 전설 2%.
- **외형**(머리색·피부·눈·머리모양): 한쪽 부모에게서 물려받음, 12%는 새로 나옴 → 자녀가 부모를 닮는다.
- 리롤(보석): 새 혼담 30, 축복 의식(자녀 다시 뽑기) 50. 뽑힌 후보는 저장되어 재접속으로 무료 리롤 불가.

### 4.6 특성 표 ✅

| 등급 | 특성 | 효과 |
|---|---|---|
| 일반 | 억센 팔 / 튼튼한 몸 / 날랜 발 / 알뜰함 | 공격 +10% / 체력 +15% / 공속 +8% / 골드 +10% |
| 희귀 | 검의 혼 / 거인의 피 / 질풍 / 매의 눈 / 장수 | 공격 +25% / 체력 +35% / 공속 +18% / 치명 +8%p / 수명 +10 |
| 영웅 | 황금손 / 광전사 / 현자의 핏줄 | 골드 +40% / 공격 +45%·체력 -10% / 명성 +30% |
| 전설 | 용의 혈통 / 불사조 | 공·체·속 +30% / 수명 +20·체력 +25% |

### 4.7 오프라인 보상 ✅
- 최대 8시간, 효율 50%. 광고 시청 시 2배.

### 4.8 가보 ✅
- 가문의 검(공격) · 방패(체력) · 반지(골드). 레벨당 +8% / +10% / +10%, 10레벨마다 x1.25 돌파.
- 유산석으로 강화, 비용 2 × 1.2^레벨. **은퇴해도 유지** → 세대를 거칠수록 "낡은 → 단단한 → 이름난 → 전설의 → 신화의" 가문의 검이 된다.

### 4.9 매일 할 것 · 업적 ✅ (임무 탭)
- **출석** 7일 주기 (보석·골드 부스트·유산석). 빠진 날이 있어도 이어서 받는다.
- **일일 임무** 3개 (몬스터 300, 수련 30, 보스 3) 각 보석 20 + 모두 완료 시 유산석 3·보석 20.
- **업적** 16개 (세대·최고 기록·보스·처치 수·돌연변이·전설 특성·가보·출석).
- 받을 보상이 있으면 임무 탭에 빨간 점.

### 4.10 은퇴 조언 ✅
- 명성 +0 이면 경고 ("다음 가주가 강해지지 않아요"), 배율이 1.3배 미만으로 오르면 주의, 그 이상이면 "다음 가주가 x○ 강해져요".

### 4.11 기기 이전 · 시간 조작 방지 · 플레이 기록 ✅
- 기기 이전 코드: 저장 데이터를 체크섬 붙은 글자 코드로 내보내고 불러온다 (서버 없이 휴대폰 변경).
- 시간 조작: 시계 되돌림 감지 시 오프라인 보상 없음. 미래 날짜로 출석을 받으면 실제 날짜가 따라잡을 때까지 다음 출석이 막힘. 서버 시간 연결 지점(`clock.setServerTime`).
- 플레이 기록: 기기 안 이벤트 로그 (세션, 튜토리얼, 벽, 은퇴, 보상, 광고, 결제 클릭 등). 분석 서비스 연결 지점(`addSink`).

### 4.12 장비 · 뽑기 · 직업 ✅ (장비 탭)
- **장비 5칸:** 무기 · 투구 · 갑옷 · 목걸이 · 반지. 가문 무기고에 쌓여 **세대가 바뀌어도 유지**.
- **등급 20단계:** 일반 · 고급 · 희귀 · 영웅 · 전설 × ★1~★4. **같은 장비 4개 → 한 단계 위** (장착 중인 1개는 재료 제외). 일괄 합성은 아래 등급부터 연쇄.
- **효과 (등급마다 ×1.25):** 무기 공격력 +10%×1.25^등급 (영웅★1 ≈ x2.5, 전설★4 ≈ x8), 투구 체력 +6%·갑옷 +10% (×1.25^등급), 목걸이 치명타 +1%p + 0.4%p×등급, 반지 골드 +8%×1.25^등급.
  - 처음엔 ×1.32 였으나 보석 수급 시뮬레이션에서 무과금 첫날 공격력 x10 → 세대 밸런스 붕괴 → 낮춤.
- **직업 = 장착한 무기:** 검 = 전사(체력 +30%, 공격력 +10%, 근접) · 활 = 궁수(공속 +30%, 치명타 +8%p, 화살) · 지팡이 = 마법사(공격력 +30%, 공속 -15%, 치명타 피해 2.5배, 마법 구슬).
- **재능(유전):** 가주마다 검·활·지팡이 재능을 타고난다 (한쪽 부모에게서, 12% 확률로 새 재능). 재능과 같은 무기를 들면 공격력 +25% → "궁수 가문"을 키우는 혈통 전략.
- **추천 장착:** 부위마다 가진 장비를 다 껴 보고 전투력(초당 피해 × √체력)이 가장 높은 것. 재능까지 계산.
- **뽑기:** 1회 보석 30, 10회 270, 하루 1번 광고 무료. 희귀도 일반 62% · 고급 27% · 희귀 8.5% · 영웅 2.2% · 전설 0.3% (항상 ★1). 부위 무기 34%(검·활·지팡이 각 1/3), 나머지 각 16.5%. **천장: 50번 안에 영웅 이상 확정.** 모든 확률은 상점 → 확률표에 공개.
- 업적: 장비 50번 뽑기, 영웅 장비, 전설 장비.

### 4.13 직업 스킬 ✅
- 쿨타임이 차면 자동 사용 (처음은 3초 뒤). 화면 왼쪽 위에 스킬 이름과 준비 막대, 준비되면 금색.
- 전사 **회오리 베기**: 10초마다 공격력 400% 한 방 · 궁수 **연사**: 8초마다 화살 5발(발당 80%) · 마법사 **메테오**: 14초마다 800% 운석.
- **손맛 연출 (v0.5)**: 모든 스킬은 `준비 동작 → 돌진/발사 → 맞는 순간 → 여운` 4박자.
  - 맞는 순간: **히트스톱**(화면이 0.06~0.11초 거의 멈춤) + 화면 번쩍임 + **카메라 확대 펀치** + 충격파 고리 + 몬스터 하얗게 번쩍·밀려남·찌그러짐 + 크게 튀어나오는 피해 숫자 + 화면 흔들림.
  - 전사: 몸을 웅크려 기를 모음 → **잔상을 남기며 돌진** → X자 초승달 베기 → 제자리로.
  - 궁수: 뒤로 물러서 활 당김 → 발마다 반동과 잔상 → 마지막 발에 히트스톱과 「5연타!」.
  - 마법사: 몸이 떠오르고 주변이 어두워지며 보랏빛 기 모음 → 회전하는 운석이 꼬리를 끌며 낙하 → 이중 충격파와 큰 폭발.
  - 스킬이 날아가는 동안 생긴 일(처치·다음 몬스터)은 **맞는 순간 뒤로 미뤄** 보여 준다 (운석이 닿기 전에 몬스터가 쓰러지는 어색함 방지).
  - 일반 공격 치명타에도 짧은 히트스톱. 설정의 「화면 흔들림」을 끄면 흔들림·확대도 꺼진다.

### 4.14 이야기 사건 ✅
- 모험 중: 튜토리얼 '가주의 일생' 이후, 최소 6분 간격, 1분마다 15% → 대략 10~15분에 한 번. 최근 본 사건은 덜 나옴.
  - 떠돌이 상인 (골드 30% ↔ 보석 20) · 옛 전장의 상자 (70% 유산석 2 / 30% 미믹) · 수상한 노인 (2살 젊어짐 ↔ 골드 2배 15분) · 길 잃은 아이 (보석 15) · 떠돌이 대장장이 (장비 1개, 뽑기 횟수·천장 제외)
- 출생·혼담: **쌍둥이** 8% (같은 유전자 아이 한 명 더) · **용의 혼약** 4% (후보 1명이 전설 특성 '용의 혈통'). 보석으로 다시 뽑을 수 있어서 확률표에 공개.

### 4.15 알림 · 설정 ✅
- 알림(앱에서만, 서버 없음): 앱을 떠날 때 예약, 돌아오면 취소. 은퇴할 나이(오프라인 노화 속도 반영) · 오프라인 보상 가득(8시간) · 다음 날 낮 12시. 첫 은퇴 뒤 한 번 허락을 묻고, 설정에서 종류별로 끄기. 정확한 알람 권한은 쓰지 않음(Play 정책).
- 설정(⚙): 소리 켜기, 배경음악·효과음 크기, 화면 흔들림, 알림, 기기 이전, 확률 정보, 처음부터, 버전.

### 4.16 다음 단계 (미구현)
- **친구 가문과 혼인 동맹**: 친구를 초대하면 친구의 가주가 내 배우자 후보로 등장 → 초대 바이럴 루프. (서버 필요)
- **가문 랭킹 시즌**: 주간 최고 스테이지 / 최다 세대. (서버 필요)
- **가계도 공유 이미지**: 한 장짜리 족보 이미지 생성 → SNS 공유 보상.
- **사건(이벤트)**: "쌍둥이 탄생", "용과의 혼약" 같은 낮은 확률 이야기 이벤트.
- **푸시 알림**: "레온이 은퇴할 나이가 되었어요", "오프라인 보상이 가득 찼어요". (앱 플러그인)

- 애플·구글도 뽑기 확률 공개를 요구. 출시 전 법률 검토 필요.

|---|---|
| 하루 보석 (첫 주 이후) | 약 150~300 (평균 ~180) |

## 6. 밸런스

자동 플레이 시뮬레이터(`src/core/autoplay.ts`)가 실제 전투 로직으로 여러 세대를 끝까지 플레이해서 수치를 검증한다.
정책: 가장 싼 수련 계속 구매, 30세 이후 4년간 기록이 안 오르면 은퇴, 유전 점수가 가장 높은 배우자·자녀 선택. 광고 부스트 없음, 접속 상태 기준.

### 목표와 결과 (시드 4개 평균, 2026-11 조정)

| 세대 | 도달 스테이지 | 세대 시간 | 비고 |
|---|---|---|---|
| 1대 | 36~38 | 9~11분 | 첫 세션 안에 은퇴까지 경험 |
| 2대 | 53~54 (+16~18) | 11~12분 | |
| 3대 | 70~74 | 11~14분 | |
| 5대 | 110~123 | 20~25분 | |
| 10대 | 218~235 | 48분 | 세대마다 +18~25스테이지 |

- 선대 기록 따라잡기: 2~9분 (세대 시간의 40% 이내, 후반은 20% 이내).
- v0.5 보스 도전 방식(자동 도전 켬 기준)으로 다시 잰 값. 시드 4개.
- 조정 전: 세대마다 +4~12, 점점 감소. 보스(8배)에서 기록이 10단위로 끊김. 따라잡기에 세대 시간의 절반.

### 조정 내역
| 항목 | 전 | 후 | 이유 |
|---|---|---|---|
| 명성 공식 | (스테이지/8)^1.7 | 3 × 1.09^(스테이지−10) | 거듭제곱은 세대가 갈수록 성장이 줄어듦 → 기하급수로 바꿔 세대마다 일정하게 성장 |
| 보스 체력 | 8배 | 3.5배 | 기록이 10단위 보스에 너무 자주 막힘 |
| 정복한 땅 | 일반 진행 | 빠른 진군 | 강해진 새 가주가 초반을 순식간에 지나가는 쾌감 |
| 1년 길이 | 30초 고정 | 30초 × 1.35^(세대−1), 최대 240초 | 1대는 빠르게, 후반은 방치형답게 길게 |
| 보스 (v0.5) | 10스테이지마다 3.5배, 지면 한 스테이지 뒤로 | 매 스테이지 정예(2.5배) + 10마다 지역(5배), 지면 같은 스테이지 유지·1.15배 강해지면 재도전 | 보스를 언제 칠지 고르는 재미, 떨어지는 좌절감 제거 |

### 확인 방법
- 목표 테스트: `npm test` (tests/balance.test.ts, 시드 3개 × 6세대). 수치를 바꿔서 목표를 벗어나면 실패한다.
- 세대별 표: `BALANCE_REPORT=1 GENS=10 SEEDS=1,2,3 npx vitest run tests/balance.report.test.ts --silent=false`

### 알려진 특성
- 최적 플레이는 대부분 30~35세 은퇴 (벽에 부딪히는 시점이 전성기 초반). 은퇴 최소 나이(30세)가 '환생 쿨타임' 역할을 한다.
- 오프라인 시간은 시뮬레이션에 포함하지 않았다 (오프라인 효율 50%, 노화 절반 속도).

## 10. 위험 요소

- **아트 일관성** → 팔레트 고정 + 종이인형(레이어) 구조 + 후처리 도구 (`docs/ART_GUIDE.md`).
