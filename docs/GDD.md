# 계승자들 — 게임 기획서 (v0.1)

> 가문의 검을 대대로 물려주는 픽셀 방치형 RPG.
> 영웅은 늙고, 은퇴하고, 자녀가 그 피를 이어받는다.

---

## 1. 한 줄 요약과 차별점

| | 기존 방치형 RPG | 계승자들 |
|---|---|---|
| 성장 대상 | 영웅 한 명(또는 수집 캐릭터)의 숫자 | **혈통** — 세대마다 바뀌는 영웅들 |
| 환생(프레스티지) | 버튼 하나로 리셋, 감정 없음 | **은퇴 → 혼인 → 후계자 선택**, 이야기가 있는 리셋 |
| 수집 | 정해진 캐릭터 목록 | 유전 조합으로 **사실상 무한한 영웅**, 가계도가 곧 도감 |
| 시간 | 쌓이기만 함 | 영웅이 **실제 시간으로 나이를 먹음** → "언제 은퇴시킬까"가 핵심 판단 |
| 공유 | 전투력 숫자 | **우리 가문 가계도 이미지** (SNS 공유 → 바이럴) |

### 핵심 재미 3가지
1. **핏줄 육성** — 좋은 특성을 가진 배우자를 맞아 원하는 특성을 고정시키는 '브리딩' 재미 (같은 특성끼리 결혼하면 유전 확률 50% → 75%).
2. **은퇴 타이밍** — 나이에 따라 전투력이 청년기 → 전성기 → 노년기로 변한다. 더 버틸지, 지금 넘겨줄지 고민하게 만든다.
3. **가문 서사** — 1대 시조부터 이어지는 가계도. 하늘이 인생의 하루처럼 새벽(청년) → 노을(노년) → 밤(은퇴)으로 바뀐다.

---

## 2. 타깃

- **1차:** 한국·일본의 방치형 RPG 유저 (20~40대). 수집·육성에 돈을 쓰는 층.
- **2차:** 가볍게 즐기는 캐주얼 유저. 픽셀 감성 + 가족 이야기로 유입.
- 세션: 하루 5~8회, 1회 2~5분 접속 + 오프라인 방치.

---

## 3. 게임 루프

| 주기 | 플레이어가 하는 일 |
|---|---|
| 몇 초 | 자동 전투 구경, 골드로 수련(공격·체력·공속) 업그레이드 |
| 한 세션 (2~5분) | 오프라인 보상 받기(광고 2배), 업그레이드, 보스 돌파 |
| 한 세대 (라이브 기준 3~6시간) | 영웅 성장 → 전성기 → 벽에 막힘 → **은퇴** → 명성 획득 |
| 하루 | 2~4세대 진행, 일일 미션, 혼담 확인 |
| 주 | 가문 랭킹 시즌, 이벤트 특성, 친구 가문과 혼인 동맹 |

## 4. 시스템 (프로토타입에 구현된 것은 ✅)

### 4.1 전투 ✅
- 스테이지마다 일반 몬스터 5마리, **10스테이지마다 보스**(30초 제한).
- 쓰러지거나 시간 초과 시 한 스테이지 뒤로 → 골드를 모아 다시 도전 (방치형 '벽').
- 지역(바이옴) 20스테이지마다 변경: 초록 들판 → 안개 숲 → 잿빛 유적.
- 전투 로직(`src/core/battle.ts`)은 화면과 분리 → 서버 검증·오프라인 계산에 그대로 사용 가능.

### 4.2 수련(업그레이드) ✅
- 검술 수련(공격), 체력 단련(체력), 발놀림(공속, 최대 50).
- 비용 = 기본 × 1.15^레벨, **25레벨마다 배율 ×2 '돌파'**.

### 4.3 나이와 수명 ✅
- 18세 시작, 기본 수명 58세 + 체력 유전자 보정 + 특성(장수·불사조).
- 나이 보정: 청년 0.8 → 전성기 1.12 → 노년 0.65 (`ageMultiplier`).
- 30세부터 자발적 은퇴 가능. 수명이 다하면 강제 은퇴.
- 오프라인 동안에는 **절반 속도**로 나이를 먹음 (자고 일어났더니 은퇴해 있는 상황 완화).

### 4.4 은퇴와 명성 ✅
- 은퇴 시 명성 = ⌊(최고 스테이지 ÷ 8)^1.7⌋ × 특성 보정.
- 명성 1당 공격·체력·골드 +5% (영구).
- 초기화: 골드, 수련, 스테이지. 유지: 명성, 보석, 가계도, **유전자**.

### 4.5 혼인과 유전 ✅
- 배우자 후보 3명. 명성이 높을수록 좋은 후보(능력치 평균↑, 특성 확률↑).
- 자녀 후보 3명 중 후계자 선택.
- **능력치**(힘·체력·민첩): 부모 평균 + 정규분포 노이즈(σ=8).
- **특성**: 부모 각 특성이 50%로 전달, 둘 다 가진 특성은 75%. 최대 2개.
- **돌연변이** 6%: 일반 60% / 희귀 28% / 영웅 10% / 전설 2%.
- **외형**(머리색·피부·눈·머리모양): 한쪽 부모에게서 물려받음, 12%는 새로 나옴 → 자녀가 부모를 닮는다.
- 리롤(보석): 새 혼담 30, 축복 의식(자녀 다시 뽑기) 50. 뽑힌 후보는 저장되어 재접속으로 무료 리롤 불가.

### 4.6 특성 표 ✅

| 등급 | 특성 | 효과 |
|---|---|---|
| 일반 | 억센 팔 / 튼튼한 몸 / 날랜 발 / 알뜰함 | 공격 +10% / 체력 +15% / 공속 +8% / 골드 +10% |
| 희귀 | 검의 혼 / 거인의 피 / 질풍 / 매의 눈 / 장수 | 공격 +25% / 체력 +35% / 공속 +18% / 치명 +8%p / 수명 +10 |
| 영웅 | 황금손 / 광전사 / 현자의 핏줄 | 골드 +40% / 공격 +45%·체력 -10% / 명성 +30% |
| 전설 | 용의 혈통 / 불사조 | 공·체·속 +30% / 수명 +20·체력 +25% |

### 4.7 오프라인 보상 ✅
- 최대 8시간, 효율 50%. 광고 시청 시 2배.

### 4.8 다음 단계 (미구현)
- **친구 가문과 혼인 동맹**: 친구를 초대하면 친구의 가주가 내 배우자 후보로 등장 → 초대 바이럴 루프.
- **가보(장비)**: 대대로 물려주는 무기. 세대를 거칠수록 강해지는 '전설의 검'.
- **가문 랭킹 시즌**: 주간 최고 스테이지 / 최다 세대.
- **가계도 공유 이미지**: 한 장짜리 족보 이미지 생성 → SNS 공유 보상.
- **사건(이벤트)**: "쌍둥이 탄생", "용과의 혼약" 같은 낮은 확률 이야기 이벤트.
- **푸시 알림**: "레온이 은퇴할 나이가 되었어요", "오프라인 보상이 가득 찼어요".

## 5. 수익 모델 (BM)

원칙: **광고로 넓게, 결제는 편의·속도·수집에.** 결제하지 않아도 끝까지 갈 수 있어야 평이 좋고 오래 간다.

### 5.1 보상형 광고 (방치형 매출의 큰 축)
| 위치 | 보상 | 하루 한도(안) |
|---|---|---|
| 오프라인 보상 | 2배 | 제한 없음 |
| 골드 부스트 | 30분간 골드 2배 (누적 연장) | 6회 |
| 보석 | +10 | 5회 |
| (예정) 혼담 1회 무료 | 새 혼담 | 3회 |

목표: DAU당 하루 광고 시청 6~10회.

### 5.2 인앱 결제
| 상품 | 가격(안) | 내용 |
|---|---|---|
| 스타터 팩 | ₩1,200 | 보석 300 + 부스트 2시간 (첫 결제 전환용) |
| 명문가 월정액 | ₩5,500 | 매일 보석 100, 광고 없이 광고 보상, 혼담 하루 1회 무료 |
| 광고 제거 | ₩6,500 | 모든 광고 보상 즉시 획득 |
| 보석 상자 | ₩1,200~₩119,000 | 보석 |
| (예정) 가문 시즌 패스 | ₩9,900 | 시즌 한정 특성·외형(왕관, 망토 색) |
| (예정) 외형 | ₩2,500~ | 가문 문장, 망토 색, 머리 모양 — 능력치 없는 꾸미기 |

### 5.3 확률형 요소와 법규
- 한국 게임산업법(2024.3.22 시행)에 따라 **확률형 아이템 확률 공개 의무**. 혼담·축복 의식처럼 유료 재화로 확률 결과를 얻는 기능이 해당될 수 있음.
- 프로토타입은 이미 **상점 → 확률 정보**에서 실제 로직과 같은 수치를 표로 공개한다. 수치는 `src/config/balance.ts` 한 곳에서만 정의 → 표와 실제가 어긋날 일이 없음.
- 애플·구글도 뽑기 확률 공개를 요구. 출시 전 법률 검토 필요.

## 6. 밸런스 메모

프로토타입 수치는 **확인용으로 빠르게** 맞춰져 있다 (1년 = 30초, 한 세대 ≈ 20분).

| 항목 | 프로토타입 | 라이브(안) |
|---|---|---|
| 1년 길이 | 30초 | 4~6분 (한 세대 3~4시간) |
| 오프라인 노화 | 절반 속도 | 절반 속도, 수명 도달 시 '은퇴 대기' 푸시 |
| 1세대 도달 스테이지 | 약 30~37 (자동 테스트 기준) | 40 전후 |

`tests/game.test.ts` 의 밸런스 스모크 테스트가 한 세대를 자동으로 끝까지 돌려서 도달 스테이지를 출력한다. 수치를 바꾸면 이 테스트로 바로 확인.

## 8. 기술 구조

- TypeScript + Phaser 4 (전투 화면) + DOM UI (패널·메뉴) + Vite.
- 출시: Capacitor로 iOS·Android 앱 포장 → AdMob(광고), RevenueCat 또는 스토어 결제(인앱).
- 게임 규칙은 `src/core/` 에 화면과 분리 → 나중에 서버(치트 방지·랭킹)로 옮기기 쉽다.
- 저장: 현재 localStorage → 앱에서는 Capacitor Preferences + 클라우드 저장.

## 10. 위험 요소

- **"늙어서 약해짐"이 짜증으로 느껴질 위험** → 노년기에도 명성 보너스는 늘어나고, 은퇴 보상 연출을 크게. 첫 은퇴는 튜토리얼로 안내.
- **방치형 시장 포화** → 혈통·가계도라는 차별점을 스토어 스크린샷 첫 장에 노출.
- **아트 일관성** → 팔레트 고정 + 종이인형(레이어) 구조 + 후처리 도구 (`docs/ART_GUIDE.md`).
